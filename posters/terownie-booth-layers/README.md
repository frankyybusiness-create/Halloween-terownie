# WAKE THE DEAD (Terownie booth poster): layers

1080 × 1350 transparent PNGs. Stack them in number order, lowest first.
In Canva, Photoshop or Figma, set **07-print-grain** to the **Overlay** blend mode at about 60–100% opacity. Every other layer uses Normal.
Text layers are rendered PNGs. The editable source is `posters/source/booth.html`.
The logo, wordmark and spiral face are cropped and recoloured from the supplied Terownie logo. Nothing in them has been redrawn.
